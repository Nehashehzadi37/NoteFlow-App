# 📝 NoteFlow App

NoteFlow is a simple web-based Notes application that allows users to create, view, edit, and manage notes easily in the browser.

---

## 🚀 Features

- 🏠 Home page  
- ⭐ Features section  
- 📝 Notes management  
- ✏️ Edit notes functionality  
- 🗑️ Delete notes support  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
